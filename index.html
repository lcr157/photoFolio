Project

게시판 CRUD

2023.08.01 → 2023.08.15 · Java, Spring Boot, JPA, HTML, CSS, JavaScript

https://github.com/lcr157/CRUD_Board

내용

  • Spring Boot와 JPA를 이용한 CRUD, 검색, 페이지 처리를 적용한 게시판과 OAuth 2.0 카카오 연동 프로젝트입니다.

구현 기능

  • 회원: 회원가입, 로그인, 회원정보 수정, 회원탈퇴
  • 게시판: CRUD, 조회수 관리, 페이징 및 검색
  • 카카오 로그인 (OAuth 2.0): 카카오 계정 연동으로 회원가입 후 로그인

느낀점

기능 구현은 이전 팀 프로젝트에서 다뤄 금방 끝날 줄 알았지만, 검색한 예제들이 정해진 형식에 맞춰져 있어 원하는 대로 제어하려면 스택 공부가 필요했습니다. 작은 코드 에러와 버전 문제 때문에 시행착오가 많아 생각보다 오래 걸렸습니다.

그래도 JPA, OAuth 2.0처럼 처음 쓰는 스택에 익숙해져서 좋은 공부가 되었습니다.
