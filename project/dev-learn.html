서비스

인터넷 강의 및 멘토링 서비스 제공 플랫폼

https://github.com/lcr157/FinalProject_DevLearn

작업 기간

2022. 06. 01 - 2022. 06. 30 (1개월)

기술 스택

JavaSpringOracle HTMLCSSJavaScript

내용

  • 인프런을 모티브로 한 인터넷 강의 및 멘토링 서비스 플랫폼을 구현했습니다.
  • 강의와 멘토링뿐 아니라 관련 스터디 모집 기능도 가능하도록 구현했습니다.

역할

로그인, 질문과 답변, 스터디 (프론트 / 백엔드 / DB)

  • 로그인: 회원가입 시 이메일 인증 및 유효성 검사를 통한 가입, 로그인 시 각종 제약 부여
  • 커뮤니티_질문과 답변: 부트스트랩 모달과 JSP를 이용한 페이지 작성, CRUD, 페이징 및 검색
  • 커뮤니티_스터디: 질문과 답변 기능 + 카카오 지도 API를 이용한 위치 정보 가져오기

프로젝트 회고

커뮤니티를 담당하면서 원하는 조건에 맞게 리스트를 가져오는 과정에서 SQL 쿼리와 MyBatis 사용법을 익힐 수 있었고, MVC 흐름과 에러가 났을 때 어디를 고쳐야 하는지에 익숙해졌습니다. 함수와 공식 문서를 읽으며 데이터 가공도 이해할 수 있었습니다.

프로젝트를 통해 소통의 중요성을 다시 느꼈고, 전체 진행 과정도 정리할 수 있었습니다.
